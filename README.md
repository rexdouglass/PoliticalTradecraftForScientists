# Political Tradecraft for Scientists

**How Science Can Survive Populism and AI**  
by Rew W. Douglass

This repository contains the source for an online Quarto book being developed live and in public.

## Read the book

<https://rexdouglass.github.io/PoliticalTradecraftForScientists/>

## Preview locally

Install [Quarto](https://quarto.org/), then run:

```bash
quarto preview
```

Every push to `main` automatically renders and deploys the book to GitHub Pages.
